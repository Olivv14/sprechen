# Sprechen product rules

These decisions are locked for this enhancement. They apply to future edits as well.

1. **Preserve the deployed product.** This checkout has compiled React bundles, assets and content, not the original TS/React project. Do not pretend it was recovered, hand-edit minified executable code, delete the old app, or rebuild a different product. Keep tracked original HTML, JS, CSS, corpus and media bytes unchanged. The existing engine remains the compatibility path. The only output-only data correction is documented in IMPLEMENTATION.md.
2. **Stay local and free.** No backend, real client data, credentials, paid service, API subscription, analytics or cloud-account invention. No copyrighted provider video/audio extraction or copied paid transcripts. Existing public links are optional online support. Do not claim provider playback was tested without evidence.
3. **Choose a language each time.** German, French, Portugal Portuguese, Italian and Tunisian/Arabic context are independent choices. No German learning landing or prerequisite unlock. Activities belong in their language page. Learning language is separate from English UI / optional Spanish translation help. Preserve the original mixed social/flirt content and original lesson identities.
4. **Honest scope.** Italian and Portuguese have empty dedicated legacy tracks. Their available existing social-scene text is a sampler, not a full course. Tunisian currently has no verified authored corpus/audio: show a useful, truthful resource state, not fabricated assessed lessons or generic Arabic presented as Derja. Do not introduce Arabic reading instruction without verified sources.
5. **Portugal only.** New Portuguese content, words, verbs, slang, media and external resources must be appropriate to Portugal. Require an exact `pt-PT` voice. Missing Portugal voice means unavailable audio plus usable text; never silently fall back to `pt-BR`, generic `pt`, or a default browser voice. Omit unreliable inherited phonetic hints. Preserve legacy data as input without presenting locked Brazil-related archive frames as Portugal teaching. No new Portuguese podcasts or video claims in this build.
6. **French first.** The integrated original French introduction covers a programmer and a company working in computer systems and AI. Sequence: read/listen/context → attempt understanding → reveal help → read/write/produce → authored dialogue with negative, success and repair → local review. System TTS is labelled; installed local voices are optional. Characters follow authored branches, not improvised video/AI. Text matching and dictation are not phoneme scoring or a pronunciation percentage.
7. **Backup is a transaction the learner approves.** Accept validated current envelopes and valid raw legacy exports. Reject malformed, foreign, unsafe-key or incompatible JSON. Validate known data structures, numbers and identities; preserve unknown legitimate metadata. Preview all incoming/current fields, explicit confirm/cancel, zero writes for invalid input/preview/cancel. Write and verify a recoverable pre-import snapshot before replacement. Offer confirmed undo. Preserve existing device-secret protection and legacy account/preferences metadata. Quarantine old migration progress so it cannot resurrect an imported-away save. Never call `localStorage.clear()` or remove unrelated keys.
8. **Progress identities are immutable.** Lesson progress uses `track.lesson`; HLR/mastery uses `track::lesson::ITEM_INDEX`. Never reorder existing items, change their IDs or reuse their identities for a new lesson. New French pilot uses `fr::intro-pilot-v1::index`. Preserve extra record fields when updating progress. Completing a conversation enrolls lines in review; it must not claim they have already passed recall.
9. **Offline means tested behaviour.** Only announce ready after the service worker has cached the local core successfully. Test navigation, full reload, deep route, exercise, save, review and online recovery with browser networking disabled. External video is never cached. Browser/system voices may remain unavailable offline. No forced reload that loses unfinished work. HTTPS/localhost is required; remote-IP HTTP is not evidence of PWA/offline success.
10. **Extend the slate/night UI.** Keep the visual character, readable help, complete flows, keyboard access and responsive behaviour. Default UI is English; Spanish is optional support. Desktop and 390×844 Chromium emulation must be checked. Do not claim this is physical iPhone/Safari testing.
11. **Respect the review boundary.** Implement and test on the Olivv14 Windows PC. Branch stays `feat/offline-language-paths-safe-backup`; baseline is `da77c50a4b7938d4d49759f0f6c85b830db63156`. No production/main edits, commit, merge or push before independent review. Do not inspect private archives, backup files, credentials, other checkouts, browser profiles or `.env` files. Tests use fresh isolated Chromium contexts and synthetic storage on an ephemeral loopback origin.
